# Aspiradora Inteligente

Proyecto realizado en el colegio utilizando Arduino.

## Descripción

Desarrollo de una aspiradora inteligente capaz de detectar obstáculos
y desplazarse de manera autónoma.

## Tecnologías utilizadas

- Arduino
- Sensores de distancia
- Motores

## Archivos

- `motor_auto_y_distancia2.ino`: código principal del proyecto.
